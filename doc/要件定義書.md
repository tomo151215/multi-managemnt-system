# 要件定義書<**multi-management-system**(仮称)>

## 目的
宮崎マルチメディア専門学校における生徒情報の管理業務を効率化し、教育および学生支援の質を向上させるため、統合型の「生徒情報管理システム」を開発する。
### 背景と課題
現状、教職員が手作業や分散した個別システム（Excel等）で管理している以下の情報は、業務の属人化や情報のサイロ化を招いている。
- 出欠状況
- 履修登録・単位状況
- 成績評価
- 就職活動の進捗状況
### 達成目標
1. 情報の完全一元管理: 教職員が上記すべての生徒情報を一ヶ所で集約・管理し、必要なデータを自動で即時取得できるようにする。
2. 学生の利便性向上: 生徒自身が自分の情報（出欠・成績・就活状況など）をいつでも閲覧できる環境を提供し、円滑な学校生活をサポートする。

## 2. 登場人物と役割

### 2.1 登場人物

| 登場人物 | 役割 |
|---|---|
| 担任 | 朝のHRでの出席確認、事前連絡の登録、無連絡欠席者への確認連絡、担当クラスの出欠管理 |
| 教科担当教員 | 担当授業の出席確認、前時限からの差分更新、遅刻・早退・欠席の登録 |
| 生徒 | HR・授業への出席、指定座席への着席、欠席・遅刻・早退などの事前連絡 |
| システム | 出席情報の継承、遅刻判定、出欠記録の保存、出席状況の集計、進級判定支援、メール送信、PDF出力 |

### 2.2 アクセス権限

| 利用者 | 権限 |
|---|---|
| 担任 | 担当クラスの全授業の出欠情報を閲覧・登録・変更 |
| 教科担当教員 | 自身の担当授業の出欠情報を登録・変更 |
| 生徒 | 自身の出欠情報を閲覧（登録・変更不可） |
| 学校管理者 | 出欠判定基準、進級規定などの設定 |

## 3. 出欠区分と判定基準

出欠情報は生徒・時限ごとに独立して管理し、確定後は以下の5区分に分類する。

| 出欠区分 | 定義 | 判定方法 |
|---|---|---|
| 出席 | 授業開始から20分未満に出席し、早退せず最後まで受講 | 教員の確認・登録 |
| 遅刻 | 授業開始から20分以上経過して出席 | 出席登録時刻に基づく自動判定 |
| 欠席 | 授業終了まで受講しなかった | 授業終了時の出席状況に基づく判定 |
| 早退 | 授業の途中で下校した | 教員による早退登録 |
| 公欠 | 学校が認める所定の事由によって授業を受講しなかった | 担任による登録 |

また、出欠が確定していない状態を「未登録」として管理する。

## 4. 出席管理方式

### 4.1 基本方針

出席管理には、**差分更新方式**と**時限ごとの出欠確定方式**を組み合わせる。

朝のHRまたは前時限の出席情報を次の授業の出欠候補として継承し、担当教員は実際の在席状況との差分のみを登録する。

各授業の出欠情報は独立して管理し、授業終了時に担当教員が保存・確定する。

なお、前時限の出席情報を継承している場合でも、現在の授業における在席確認は必須とする。

### 4.2 出席情報の継承ルール

| 前時限・事前情報 | 次時限の表示・処理 |
|---|---|
| 出席 | 出席候補として表示 |
| 欠席 | 欠席候補として表示 |
| 遅刻後に出席 | 次時限は出席候補として表示 |
| 早退 | 以降の時限を欠席候補として表示 |
| 事前欠席連絡 | 対象時限に欠席候補として表示 |
| 公欠連絡 | 対象時限に公欠候補として表示 |
| 事前遅刻・早退連絡 | 対象時限に遅刻・早退候補として表示 |

授業途中から登校した生徒は、授業開始から20分未満であれば出席候補、20分以上であれば遅刻候補に変更する。

いずれの候補も授業終了時の保存によって確定する。

## 5. 出席管理の業務フロー

### 5.1 事前連絡の登録

生徒から欠席・遅刻・早退・公欠などの連絡があった場合、担任が事前に登録する。

#### 登録内容

| 項目 | 内容 |
|---|---|
| 対象生徒 | 連絡対象の生徒 |
| 対象日 | 欠席・遅刻・早退などの予定日 |
| 対象時限 | 終日または一部時限 |
| 連絡種別 | 欠席・遅刻予定・早退予定・公欠申請など |
| 連絡理由 | 事前連絡の理由 |
| 備考 | 必要に応じた補足情報 |

#### 業務ルール

- 終日欠席は、その日の全授業に対して一括登録できる
- 一部時限のみの欠席・公欠にも対応する
- 登録内容は対象授業の出欠候補として表示する
- 事前連絡だけでは出欠を確定しない
- 実際の出席状況に応じて候補を変更できる
- 各授業の終了時に教科担当教員が出欠を確定する
- 担任は事前連絡を編集・取り消しでき、変更履歴を保持する

### 5.2 朝のHRにおける出席確認

#### 登録時間

原則として、朝のHRの登録可能時間を **9:30〜9:40** とする。

登録時間は学校管理者が変更できる。

#### 業務フロー

1. 担任が担当クラスの出席登録画面を開く
2. システムが登録済みの座席表と事前連絡を表示する
3. 担任が実際の在席状況を確認する
4. 在席生徒を出席候補、不在生徒を欠席候補として登録する
5. 担任が出席登録を確定する
6. システムがHRの出席状況と登録時刻を保存する
7. 確定した情報を1時限目の出欠候補に利用する

#### 登録時間を超過した場合

9:40以降は通常のHR登録を締め切る。

- HRの出席状態を「未登録」として管理する
- 1時限目の教科担当教員が出席状況を確認する

### 5.3 授業開始時の出席確認

各授業の教科担当教員が、座席表を利用して出席確認を行う。

#### 業務フロー

1. 教科担当教員が担当授業を選択する
2. システムが前時限の出席情報と事前連絡を取得する
3. 座席表に継承した出欠候補を表示する
4. 教科担当教員が実際の在席状況と照合する
5. 変更のある生徒のみ出欠候補を更新する
6. 授業終了時に担当教員が出欠を保存する
7. システムが当該時限の出欠情報を確定する

#### 業務ルール

- 前時限の出席情報は候補としてのみ使用する
- 各授業で実際の在席確認を必須とする
- 教員は原則として差分のみを登録する
- 出欠記録は授業ごとに独立して保存する
- 過去の時限の確定済み出欠情報を保持する

### 5.4 授業途中の入室・遅刻登録

授業開始後に生徒が入室した場合、教科担当教員が対象生徒を選択して登録する。

#### 遅刻判定基準

授業開始時刻を `T`、実際の入室時刻を `A` とする。

| 条件 | 出欠判定 |
|---|---|
| A ＜ T + 20分 | 出席 |
| A ≧ T + 20分 | 遅刻 |
| 授業終了まで未入室 | 欠席 |

#### 業務フロー

1. 生徒が授業途中に入室する
2. 教科担当教員が座席表から対象生徒を選択する
3. システムが登録時刻を記録する
4. 授業開始時刻からの経過時間を計算する
5. 20分未満は出席候補、20分以上は遅刻候補に変更する
6. 授業終了時に担当教員が保存し、出欠を確定する

#### 業務ルール

- 遅刻判定は登録時刻を基準として自動で行う
- 登録操作の遅れによって誤判定された場合は担任が訂正できる
- 遅刻した生徒は、次時限以降は出席候補として表示する
- 判定結果は当該時限の出欠情報として保存する

### 5.5 早退登録

授業途中で生徒が下校した場合、教員が対象生徒の早退を登録する。

#### 業務ルール

- 早退した時限は早退候補として管理する
- 以降の時限は欠席候補として表示する
- 各授業終了時に担当教員が出欠を確定する

### 5.6 出欠の確定・訂正

各授業の終了時に、担当教員が出欠情報を保存して確定する。

#### 業務ルール

- 出欠候補を確定した出欠区分として保存する
- 出欠情報は生徒・授業単位で保持する
- 過去の出欠記録を保持する
- 担任および権限を持つ教科担当教員は出欠情報を訂正できる
- 訂正前後の情報と変更履歴を保持する

## 6. 無連絡欠席者への確認連絡

担任は、無連絡欠席者に対して教員画面から確認メールを送信できる。

### 6.1 必要機能

- 対象生徒への個別送信
- 複数生徒への一斉送信
- メールテンプレートの登録・選択
- 宛先・本文の送信前確認
- 送信履歴の保存
- 送信成功・失敗状況の表示
- 重複送信の警告

### 6.2 業務ルール

- 同一生徒に対する同一日の確認メールの重複送信を抑制する
- 送信対象の抽出と実際の送信を分離する
- メールは教員の確認後に送信する
- 一斉送信では、他の生徒のメールアドレスや出欠情報を公開しない
- 欠席後に連絡が確認された場合は、無連絡欠席者一覧を更新する

## 7. 進級規定の管理・判定支援

### 7.1 科目別出席管理

進級判定に必要な出欠情報を、科目・生徒単位で集計する。

#### 管理項目

| 項目 | 内容 |
|---|---|
| 科目名 | 集計対象の科目 |
| 授業予定時数 | 当該科目の予定授業時数 |
| 実施済み授業時数 | 確定した実施授業時数 |
| 出席時数 | 生徒が出席した授業時数 |
| 欠席時数 | 生徒が欠席した授業時数 |
| 遅刻回数 | 遅刻した回数 |
| 早退回数 | 早退した回数 |
| 公欠回数 | 公欠となった回数 |
| 進級基準 | 必要出席率または許容欠席時数 |

### 7.2 進級規定の設定

学校管理者は、学校の規定に従って以下の判定条件を設定できる。

- 科目ごとの最低出席率
- 許容欠席時数
- 遅刻・早退の欠席換算基準
- 公欠の集計方法
- 判定対象期間
- 進級リスクに関する警告基準

学校ごとの規定に対応できるよう、出席回数・時数の計算方法は固定せず、設定可能とする。

### 7.3 出席状況の自動計算

授業の出欠情報が確定または訂正された際、システムが進級判定に必要な数値を再計算する。

#### 算出項目

- 現在の科目別出席率
- 現在までの欠席時数
- 許容される残り欠席時数
- 今後必要となる出席時数
- 現在の出席ペースが継続した場合の予測出席率
- 現時点での進級規定への抵触状況

### 7.4 進級リスク判定

出席状況に基づき、生徒の進級リスクを4段階で表示する。

| 判定 | 内容 |
|---|---|
| 正常 | 現在の出席状況に問題がない |
| 注意 | 出席ペースが低下し、今後規定に抵触する可能性がある |
| 警告 | 欠席可能時数が少なく、進級規定への抵触リスクが高い |
| 規定抵触 | 設定された出席基準を満たしていない、または残りの授業すべてに出席しても基準を満たせない |

#### 業務ルール

- 判定結果を教員画面に表示する
- 生徒単位・科目単位で確認できる
- 注意・警告対象者を一覧表示する
- 判定に使用した出席数・残り授業数・基準値を確認できる
- 未確定の出欠情報がある場合は、その影響を明示する
- 出席ペースによる予測と、学校規定に基づく判定を区別する

最終的な進級可否は学校が決定し、システムはその判断を支援する。

## 8. 出席状況の集計・帳票出力

### 8.1 期間別集計

担任および権限を持つ教職員は、期間を指定して出席状況を確認できる。

#### 集計対象期間

- 日別
- 週別
- 月別
- 任意期間（開始日・終了日を指定）
- 前期
- 後期
- 年間
- 2年間

#### 表示内容

| 項目 | 内容 |
|---|---|
| 生徒別出欠一覧 | 生徒ごとの出欠記録 |
| 科目別出欠一覧 | 科目ごとの出欠記録 |
| 出席 | 回数・時数 |
| 欠席 | 回数・時数 |
| 遅刻 | 回数 |
| 早退 | 回数 |
| 公欠 | 回数 |
| 出席率 | 対象期間の出席率 |
| 進級リスク | 進級規定に基づく判定結果 |

### 8.2 検索・絞り込み

以下の条件で出欠情報を検索・絞り込みできる。

- クラス
- 生徒氏名・学籍番号
- 科目
- 日付・期間
- 出欠区分
- 進級リスク判定

### 8.3 PDF帳票出力

家庭への通知および校内業務で使用する出席情報を、PDF形式で出力する。

#### 出力内容

- 学校名
- 生徒氏名・学籍番号・クラス
- 対象期間
- 科目別出席状況
- 期間内の出欠集計
- 出席率
- 必要に応じた学校からの連絡事項
- 出力日

#### 業務ルール

- 生徒単位でPDFを出力できる
- クラス単位で複数生徒分のPDFを一括生成できる
- 集計対象期間を指定できる
- 未確定の出欠情報がある場合は、その旨を明示する
- 権限のない生徒の個人情報を含む帳票は出力できない
