# 要件定義書<**multi-management-system**(仮称)>

## 目的
宮崎マルチメディア専門学校における生徒情報の管理業務を効率化し、教育および学生支援の質を向上させるため、統合型の「生徒情報管理システム」を開発する。
### 背景と課題
現状、教職員が手作業や分散した個別システム（Excel等）で管理している以下の情報は、業務の属人化や情報のサイロ化を招いている。
- 出欠状況
- 履修登録・単位状況
- 成績評価
- 就職活動の進捗状況
### 達成目標
1. 情報の完全一元管理: 教職員が上記すべての生徒情報を一ヶ所で集約・管理し、必要なデータを自動で即時取得できるようにする。
2. 学生の利便性向上: 生徒自身が自分の情報（出欠・成績・就活状況など）をいつでも閲覧できる環境を提供し、円滑な学校生活をサポートする。

## 機能・業務要件

### ログイン機能 
ユーザー（生徒および教職員）がシステムに安全にアクセスし、それぞれの権限に応じた管理画面へ正しく遷移するための認証機能を提供する。

#### 認証情報（ID / パスワード）仕様
- ID要件
  * **形式**: 学校配布のメールアドレス
  * **接頭辞ルール**:
    * **生徒**: `std`から始まるメールアドレス（例: `std_mmc11111@student.multi-m.ac.jp`）
    * **教職員**: `tch`から始まるメールアドレス（例: `tch_mmc11111@teacher.multi-m.ac.jp`）
- パスワード要件
  * **初期パスワード**: システム管理側でランダムに発行した一次パスワードを使用。
  * **パスワードポリシー（変更時）**:
    * 文字数: **12文字以上**
    * 使用可能文字: 英大文字、英小文字、数字、記号の**4種**を必須とする

#### ログイン処理・遷移フロー
##### ログイン画面
* メールアドレス（ID）とパスワードの入力フォームを表示。
* 「ログイン」ボタン、「パスワードを忘れた方はこちら」のリンクを配置。
##### 認証成功時の挙動
* **ロール別画面遷移**:
  * **生徒権限**: 生徒用ダッシュボード（管理画面）へ遷移。
  * **教職員権限**: 教職員用ダッシュボード（管理画面）へ遷移。
* **アクセス制御（認可）**:
*  生徒アカウントが教職員用URLへ直接アクセスした場合、およびその逆の場合は**403 Forbidden**を表示し、遷移をブロックする。
##### ログイン失敗時の挙動
* 同一のログイン画面へ戻り、エラーメッセージを表示する。
* **セキュリティ配慮**: エラーメッセージはIDが存在しないのか、パスワードが違うのかを特定させない共通文言とする。

#### セッション管理
* **通信暗号化**: 全通信をHTTPS（TLS 1.3以上推奨）で強制暗号化する。
* **セッションタイムアウト**: 無操作状態が**30分間**続いた場合、自動的にログアウト処理を行い、ログイン画面へ遷移させる。
* **確実なログアウト**: 画面上の「ログアウト」ボタン押下時に、サーバー側のセッションおよびクライアント側のクッキーを完全に破棄する。

#### パスワードを変更
- 生徒管理画面でパスワードを変更
  - 現在ログインしているので、本人確認方法を「現在のパスワード」の入力のみとする
  - 現在のパスワード、新しいパスワード、新しいパスワード（確認用）の3つを入力。
  - 入力内容および現在のパスワードが正しい場合、変更を保存。
- ログイン画面で「パスワードを忘れた方はこちら」のリンク先でパスワード変更
  - 名前＋学籍番号/教職員番号＋生年月日で本人確認をする
  - 新しいパスワード、新しいパスワード（確認用）の2つを入力

### 時間割管理
#### 履修科目・基本情報の管理
学科・コース・学年別の共通科目に加え、生徒ごとの選択科目を管理し、各生徒に適用される時間割を構成する。

| 機能 | 概要 |
|---|---|
| 基本情報の登録・編集 | 科目・教員・教室・クラスなど、時間割作成に必要な情報を管理 |
| 履修科目の管理 | 学科・コース・学年に対応する科目と、生徒ごとの選択科目を登録・変更 |
| 個別時間割への反映 | 所属学科・コース・学年の共通科目と、本人が履修する選択科目を表示 |

#### 時間割テンプレート・日別時間割の管理
時間割は**週時間割テンプレートを通常日の初期値**として使用し、変更が必要な日・時限のみ個別に編集する。テンプレートの内容どおりに授業を行う場合、日ごとの登録操作は不要とする。

| 機能 | 概要 |
|---|---|
| 週時間割テンプレート | 学科・コース・学年別に曜日・時限・科目・担当教員・教室を設定・変更 |
| 初期表示 | テンプレート未設定かつ個別登録がない時間割は空欄で表示 |
| 日付への反映 | テンプレートを指定期間のカレンダーへ一括適用可能。通常日は個別操作なしでもテンプレートを適用した時間割を表示 |
| テンプレート再適用 | 対象期間の時間割をテンプレートの内容で上書き。ただし出席記録が確定済みの授業は変更不可 |
| 日別・週別の調整 | 授業の偏り、科目・担当教員・教室の変更、代講などを日・時限単位で登録・変更 |
| 特殊日程 | 休日・休校・試験・学校行事に応じて当日の時間割を調整 |
| 選択科目 | 同じ学科・コース・学年でも、生徒ごとの履修科目に応じて異なる時間割を表示 |

- **休講・補講の専用区分は設けない。** 通常授業の科目が別の科目に変わる場合は、その日の時間割を変更し、変更後の科目について通常の出席確認・時数集計を行う。
- 時間割を変更しても、別の日・時限のテンプレートおよび個別設定を変更しない。
- **確定済みの出席記録が存在する授業の時間割変更は禁止**する。既存の出席情報は保持する。

#### 制約チェック・変更履歴

| 機能 | 概要 |
|---|---|
| 教員の重複防止 | 同じ日時に同一教員を複数の授業へ割り当てない |
| 教室の重複防止 | 同じ日時に同一教室を複数の授業へ割り当てない |
| 保存時の検証 | 重複がある場合は警告を表示して保存を拒否し、修正後に再登録させる |
| 変更履歴 | 科目・担当教員・教室・日程などの時間割変更内容を履歴として保存 |
| 確定済み授業の保護 | 出席情報が確定した授業の時間割変更・上書きを拒否 |

#### 授業時数の管理・達成予測
科目ごとの**授業提供側の時数**を時間割に基づいて集計する。生徒個人の出席実績・進級リスク判定は、既存の「出席管理」で扱う。

| 指標 | 算出・表示内容 |
|---|---|
| 実施済み授業時数 | 当該科目について実施済みの授業時間を集計 |
| 今後の予定授業時数 | 現時点の時間割に登録された今後の授業時間を集計 |
| 年度内の授業時数見込み | 実施済み授業時数 ＋ 今後の予定授業時数 |
| 規定時数との比較 | 年度内の授業時数見込みと、科目ごとの規定時数を比較して到達見込み・過不足を表示 |

- 授業時数は**各授業の実時間**に基づいて計算する。
- 時間割の登録・変更を反映して集計・予測結果を更新する。
- 試験は授業時数に含めず、学校行事は「社会常識」の時数として扱う。
- 休校・公欠に関する時数換算は、既存の「科目別出席時数の管理」に定める規則を維持する。

#### 画面別要件

| 利用者 | 画面・機能 |
|---|---|
| 生徒 | 当日の授業一覧、日付選択による日別時間割、週選択による週時間割を閲覧 |
| 生徒 | 自身の所属学科・コース・学年の共通科目と、本人の選択科目のみを閲覧 |
| 生徒 | 登録されていない日・時限は空欄として表示 |
| 生徒 | 履修科目欄に試験関連情報を表示。試験日は時間割の予定、試験結果は成績評価で保持する情報を参照し、専用の登録項目は設けない |
| 教員 | 月間カレンダーから週を選択し、日別・時限別の時間割を登録・変更 |
| 教員 | 全教員が週時間割テンプレート、日別時間割および必要な基本情報を登録・編集 |
| 教員 | 教員・教室の重複警告、変更履歴、科目別の授業時数・到達見込みを確認 |

#### 行事予定

休日・休校・試験・学校行事などをカレンダー上で確認できるようにする。各日程は時間割に反映し、科目別の授業時数集計と整合させる。

| 区分 | 取扱い |
|---|---|
| 休日・長期休み | 年間日程で設定し、通常授業を割り当てない日として扱う |
| 休校 | 休校として表示し、時数換算は既存の出席管理の規則に従う |
| 試験 | 試験日をカレンダー・時間割に表示。授業時数には算入しない |
| 学校行事 | カレンダー・時間割に反映し、「社会常識」の時数として算入 |

- 試験の表示は**時間割・日程の設定によるもの**とし、試験日・試験範囲・追試・再試に関する**専用の情報登録機能は設けない**。


### 出席管理

#### 機能要件

学校における出欠状況の管理・通知業務を正確かつ効率的に行う。主な機能は以下のとおり。

| 機能 | 概要 |
|---|---|
| 出席情報の自動継承 | 朝のHRまたは前時限の出欠情報を引き継ぎ、教員は差分のみを登録 |
| 座席表による出席確認 | 実際の座席配置を再現し、出欠状況を視覚的に確認・変更 |
| 時限単位の出欠管理 | 生徒・時限ごとに出欠を独立して記録し、過去の情報を保持 |
| 進級判定の支援 | 科目別の出席状況・出席率を集計し、進級規定への抵触リスクを可視化 |
| 連絡業務の効率化 | 家庭向け出席情報PDFの出力 |
| 出席記録の確認・訂正 | 登録済みの出欠情報を確認・訂正 |
| 出席記録の閲覧 | 教員・生徒が出席記録を閲覧 |

##### 出欠区分

出欠情報は生徒・時限ごとに管理し、確定時に以下の5区分に分類する。

| 出欠区分 | 定義 | 判定方法 |
|---|---|---|
| 出席 | 授業開始から20分未満に出席し、早退せず最後まで受講 | 教員による確認・登録 |
| 遅刻 | 授業開始から20分以上経過して出席 | 出席登録時刻に基づく自動判定 |
| 欠席 | 授業終了まで受講しなかった | 授業終了時の出席状況に基づく判定 |
| 早退 | 授業の途中で下校した | 教員による早退登録 |
| 公欠 | 学校が認める所定の事由により授業を受講しなかった | 担任による登録 |

##### 出席情報の継承

各授業の開始時には、朝のHRまたは前時限の確定情報を引き継ぎ、出欠候補として表示する。

| 前時限の確定情報 | 次時限の初期状態 |
|---|---|
| 出席 | 出席候補 |
| 欠席 | 欠席候補 |
| 遅刻 | 出席候補 |
| 早退 | 欠席候補 |
| 公欠 | 公欠候補 |

継承元の情報が存在しない場合は、未登録または事前連絡に基づく候補として表示する。出欠候補は当該時限の出席確認に使用する初期状態であり、**前時限の確定情報を変更するものではない**。

##### 出欠情報の登録・確定

出欠情報の登録は、以下の手順で行う。

1. **事前連絡の登録**
   - 担任が欠席・遅刻・早退・公欠などの事前連絡を登録する。
2. **朝のHRでの出席確認**
   - 担任が座席表で出欠を確認・登録する。
   - 登録を忘れ未登録の場合は、そのまま未登録として、1限の担当教員に全員の出席を登録させる。
3. **各授業開始時の出席確認**
   - HRまたは前時限の確定情報から出欠候補を自動生成する。
   - 担当教員は実際の出席状況と照合し、異なる生徒のみ候補を変更する。
   - 継承情報がない生徒については、出席状況を確認して候補を設定する。
4. **授業中の出欠変更**
   - 途中入室・早退が発生した場合、担当教員が該当生徒の候補を変更する。
   - 途中入室については、画面に表示される授業開始からの経過時間と遅刻判定に従って登録する。
   - 変更のない生徒については、既存の候補を維持する。
5. **授業終了時の確定**
   - 担当教員が全生徒の出欠候補を最終確認する。
   - 保存ボタンを押すことで、当該時限の出欠情報を確定する。
   - 保存を複数回押した場合上書きされる
   - 確定情報を出席率・進級判定用の集計に反映し、さらに次時限の出欠候補の継承元とする。

##### 科目別出席時数の管理

| 機能 | 概要 |
|---|---|
| 年間日程の設定 | 授業日程・長期休みなどを設定し、計算材料にする |
| 規定時数の設定 | 科目ごとに進級に必要な出席時数を設定 |
| 出席時数の集計 | 確定した出欠情報から科目・生徒別の累積出席時数を算出 |
| 特殊日程の換算 | 休校・公欠は本来予定されていた科目の時数として算入 |
| 試験・行事の処理 | 試験は授業時数に含めず、学校行事は「社会常識」の時数として算入 |
| 自動再計算 | 出欠情報の確定・訂正時に集計値と判定結果を更新 |

##### 出席ペースの算出

年間総授業時数が固定されないため、**規定時数と年度内の経過期間に基づいて出席ペースを評価する**。

| 指標 | 計算式 |
|---|---|
| 規定時数達成率 | 累積出席時数 ÷ 規定時数 × 100 |
| 必要出席ペース | 規定時数 ÷ 年間授業対象週数 |
| 実績出席ペース | 累積出席時数 ÷ 経過授業対象週数 |
| 出席ペース達成率 | 実績出席ペース ÷ 必要出席ペース × 100 |
| 年度末予測時数 | 実績出席ペース × 年間授業対象週数 |
| 予測過不足時数 | 年度末予測時数 − 規定時数 |

- 授業対象週数は科目の対象期間に基づいて算出する
- 年度末予測は現在までの実績を基準とし、将来の時間割変更によって変動する

#### 進級リスク判定

出席ペース達成率・年度末予測時数・欠席可能時数に基づき、科目ごとの進級リスクを4段階で判定する。

| 判定 | 判定基準 |
|---|---|
| 正常 | 規定時数を達成済み、または出席ペース達成率が100%以上 |
| 注意 | 出席ペース達成率が90%以上100%未満 |
| 警告 | 出席ペース達成率が90%未満 |
| 規定抵触 | 規定時数に到達できないことが確定 |


#### 判定結果の表示

| 機能 | 概要 |
|---|---|
| 生徒別表示 | 生徒ごとの総合判定と科目別判定を一覧表示 |
| 科目別表示 | 科目ごとの規定時数・出席時数・達成率・予測時数を表示 |
| リスク対象者一覧 | 一科目でも注意・警告・規定抵触の生徒を抽出 |
| 判定根拠の表示 | 判定に使用した数値を表示 |
| 自動更新 | 出欠情報の変更に連動して判定結果を更新 |

##### PDF帳票出力

家庭への通知および校内業務で使用する出席情報を、PDF形式で以下の項目を生徒単位かつ1日単位で出力可能。

- 学校名
- 生徒氏名・学籍番号・クラス
- 対象期間
- 科目別出席状況[規定到達・順調・警告・未達確定]
- 期間内の科目別出欠集計[時間]
- 出席率
- 必要に応じた学校からの連絡事項
- 出力日

### 成績評価
生徒の試験結果と科目別の最終評価を学期ごとに管理し、生徒本人と担当教員が必要な情報を確認できるようにする。

#### 成績・試験結果の管理

| 機能 | 概要 |
|---|---|
| 試験結果の登録・編集 | 担当教員が担当科目の生徒別試験点数を登録・編集 |
| 最終評価点の保持 | 試験点数・平常点などの評価項目を合算した**最終評価点**を科目・生徒・学期ごとに保持 |
| 科目評価 | 最終評価点からA・B・C・Dの評価を判定 |
| 受験区分 | 通常試験・追試・再試の受験状況を管理・表示 |
| 追試・再試の点数 | 追試・再試を受験した場合は、該当の試験点数で通常試験の点数を置き換える |
| 統計情報 | 同一学科・コース内を対象として科目別平均点・偏差値・順位を表示 |

##### 評価基準

| 評価 | 最終評価点 | 表示 |
|---|---|---|
| A | 80～100点 | A |
| B | 70～79点 | B |
| C | 60～69点 | C |
| D | 0～59点 | 赤点として警告を表示 |

- 対象学期は**1年次・2年次の前期・後期**とする。
- 評価区分は**最終評価点**に適用する。試験点数のみで最終評価を確定しない。
- 最終評価点に含める各項目の配点・加算方法は本要件では定めない。

#### 画面別要件

| 利用者 | 画面・機能 |
|---|---|
| 生徒 | 1・2年次の前期・後期を選択して、自身の科目別試験点数と評価（A～D）を確認 |
| 生徒 | 科目別平均点を確認。試験点数の表示に平常点は含めない |
| 生徒 | 赤点の場合、警告を表示 |
| 教員 | 担当科目の生徒別試験点数・最終評価点・評価を登録・確認・編集 |
| 教員 | 試験点数と平常点を含む評価情報、科目別平均点・偏差値・順位を確認 |
| 教員 | 赤点の生徒、各評価区分の生徒を色分けして表示 |
| 教員 | 生徒の受験状況（通常試験・追試・再試）を確認 |

#### 管理データ

| 分類 | データ項目 |
|---|---|
| 識別情報 | 生徒、科目、学年、学期（前期・後期） |
| 試験情報 | 試験点数（0～100）、受験区分（通常・追試・再試） |
| 評価情報 | 平常点などの評価要素、最終評価点（0～100）、評価（A・B・C・D） |
| 集計情報 | 科目別平均点、偏差値、順位（同一学科・コース内） |

- **課題の登録・提出・提出状況管理機能は設けない。**
- **試験範囲・試験日・追試・再試の専用情報登録機能は設けない。** 試験日については時間割管理のカレンダー表示を利用する。
- 成績の変更履歴を記録する追加機能は設けない。

### 就職活動管理
生徒自身が志望・受験企業ごとの選考状況を登録・更新し、生徒本人と教員が同じ進捗情報を閲覧できるようにする。教員は生徒情報・資格・提出書類などを一元的に確認・管理する。

#### 機能要件

| 機能 | 概要 |
|---|---|
| 生徒による選考情報登録 | 生徒本人が志望・受験企業名、選考段階、選考日程、選考結果を登録・更新 |
| 選考進捗の共有 | 生徒本人と教員が、企業ごとの選考状況と合否・辞退の情報を閲覧 |
| 資格情報の管理 | 生徒が教員に取得資格を報告し、**教員のみ**が資格名・取得年月を登録・更新 |
| 内定先情報 | 内定先企業名・決定日を登録・参照 |
| 就職希望・生徒情報 | 希望勤務地（県内・県外・その他）、担当教員、連絡先、特記事項などを管理 |
| 提出書類の状況管理 | 履歴書・エントリーシート（ES）の提出状態を管理 |
| 証明書申請状況 | 成績証明書・卒業見込み証明書の申請状況を管理。**証明書の発行機能は設けない** |
| 教員メモ | 就職支援用の教員メモ・特記事項を管理 |
| 集計・絞り込み | エントリー数、学科平均などを参照し、就職活動の状況で名簿を絞り込み・並べ替え |
| 連絡メール | 教員が対象生徒を抽出し、説明会・面接日程・選考結果などの案内を個別・一括でメール送信 |

##### 就活ステータス（選考段階）
志望・受験企業ごとに次の区分を選択できるようにする。

| 区分 | 選択値 |
|---|---|
| 選考前・説明会 | 受験検討／会社説明会 |
| 書類・試験 | 書類選考／WEBテスト／筆記試験 |
| 面接 | 1次面接／2次面接／3次面接／4次面接／最終面接 |
| その他 | その他（**生徒本人が内容を設定**） |

- **選考結果**は選考段階と区別し、**進行中・合格・不合格・辞退**で管理する。
- 従前の案にあった「未開始・活動中・活動中（内定済み）・終了」の4区分を就活ステータスとしては採用しない。
- 複数の企業を登録できるようにし、企業ごとに進捗と日程を確認する。

#### 画面別要件

##### 生徒用画面

| 表示・操作 | 内容 |
|---|---|
| 企業情報の登録・更新 | 自身の志望・受験企業を登録・編集 |
| 選考状況の登録・更新 | 就活ステータス、選考日程、合否・辞退を登録・編集 |
| 就職活動情報の閲覧 | 自身が登録した企業と選考状況を確認 |

##### 教員用：生徒名簿一覧画面

| 表示・操作 | 内容 |
|---|---|
| 生徒名簿 | 出席番号順のスクロール形式で表示。生徒を選択すると個別管理画面へ遷移 |
| 検索・絞り込み | 就職活動の開始状況・選考段階などで検索、絞り込み、ソート |
| 進捗の視覚化 | 選考状況を色・枠などで区別して表示 |
| 集計 | 生徒ごとのエントリー数、学科平均などを参照 |
| メール送信 | 抽出した生徒へ個別または一括で案内メールを送信 |

##### 教員用：学生就活情報の管理画面

| 領域 | 表示・操作 |

| 基本情報 | 学籍番号、氏名、所属学科・コース、担当教員、電話番号、メールアドレス、希望勤務地 |
| 選考進捗 | 志望・受験企業名、選考段階、選考日程、選考結果、エントリー数 |
| 内定情報 | 内定先企業名、決定日 |
| 資格一覧 | 保有資格・免許の名称、取得年月 |
| 提出書類 | 履歴書・ESの提出状況（未提出・確認中・完了など）、証明書の申請状況 |
| 連絡履歴 | 日程案内・選考結果などのメール送信履歴 |
