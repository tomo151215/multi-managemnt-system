# 環境構築
## 1. JDK（Java Development Kit）のインストール
1. [JDK-25](https://jdk.java.net/java-se-ri/25)をクリック
2. Windows 11 x64 Java Development Kitをクリック<br>
   <img src=img/JDKインストール/A.png width=350px>
3. ファイルを展開する
4. `C:\Program Files`直下に`Java`フォルダを作ってそこに展開したファイル一式を置く。実際にはどこでもいいがそろえる。
5. コントロールパネル→システムとセキュリティ押下<br>
    <img src=img/JDKインストール/B.png width=350px>
6. システム押下<br>
    <img src=img/JDKインストール/C.png width=350px>
7. システムの詳細設定押下<br>
    <img src=img/JDKインストール/D.png width=350px>
8. 環境変数（N）押下<br>
    <img src=img/JDKインストール/E.png width=350px>
9. ユーザー環境変数の追加のため新規押下<br>
    <img src=img/JDKインストール/F.png width=350px>
10. 変数名を「`JAVA_HOME`」にし、変数値にJDK(Java Development Kit) のインストールにてJDKを保存した場所を記述。（絶対パス）→　OK<br>
    <img src=img/JDKインストール/G.png width=350px>
11. ユーザー環境変数の`Path`をダブルクリック → 新規押下<br>
    <img src=img/JDKインストール/H.png width=350px>
12. Pathに新たに「`%JAVA_HOME%/bin`」を追加 → OK<br>
    <img src=img/JDKインストール/I.png width=350px>
13. コマンドプロンプトを開き`java -version`とコマンドを打って以下の様にバージョン情報が出力されれば環境構築は完了<br>
    <img src=img/JDKインストール/J.png width=600px>

## 2. VScode設定①
1. 拡張機能**Extension Pack for Java**のインストール<br>
   <img src=img/VScode拡張機能/A.png width=450px>
2. デスクトップにサンプルフォルダを作成し、VScodeで開く。（フォルダを信頼するダイアログが表示される場合がある。そのときは信頼するを押下）
3. エクスプローラー上で右クリック → New JavaFile → Class → クラス名Mainにする → Mainクラスが生成されるので以下のコードを張り付ける → このコードが実行(クラス宣言直前のRunボタン押下)できたらJDK25で正常に環境構築できている証拠になる
   ```java
   public class Main {
        void main() {
            IO.println("Game");　　// Game
        }
    }
   ```

## 3. Apache Tomcat インストール
1. [Tomcat11](https://tomcat.apache.org/download-11.cgi)のダウンロード先にアクセス
2. Windowsなので`Core`の中の`zip`をクリックしダウンロード（pgp, sha-512は改ざん検知のためのハッシュ値なので今回は関係ない）<br>
   <img src=img/Apache%20Tomcat/A.png width=350px>
3. 任意の場所でダウンロードしたTomcatを解凍する

## 4. VScode設定②
1. 拡張機能`Community Server Connector`をインストールする<br>
   <img src=img/VScode拡張機能/B.png width=350px>
2. VScode上部の表示 → ビューを開く... → Serversをクリックし、Serversパネルを表示する
3. Serversパネルの Create New Server（または「＋」ボタン）をクリックし、「No, use server on disk」 を選択
4. 先ほど解凍したTomcatのフォルダ（ルートフォルダ）を選択。ルートフォルダとはTomcatのbinフォルダの親のこと。Windowsは解凍時にルートの親に同じ名前のフォルダをかぶせるので注意。
5. ServerNameをTomcat 11にする。（何でもよい）
6. ServersパネルにTomcat 11があれば、右クリック → Start Serverをクリック → ブラウザで[](http://localhost:8080)にアクセス → Tomcatトップページが開ければ成功 → 確認したらStop Serverをクリックしてサーバーを落とす<br>
   <img src=img/VScode拡張機能/C.png width=350px>
## 5. Mavenインストール

## 6. Mavenプロジェクト作成（チームリーダー（gitHubリポジトリ作成者）のみ作成）
1. エクスプローラー上で右クリック → Maven → New Project 
2. maven-archetype-webapp選択
3. 一番新しいバージョン（数字が大きいもの）を選択
4. GroupIdとして`team.multi.project`とする
5. artifactId（プロジェクトID）として`multi-management-system`とする
6. バージョン（1.0-SNAPSHOT など）やパッケージ名の確認が出る。基本はそのままEnterで進める
7. プロジェクト保存先を聞かれるので任意の場所に保存する。この場合本リポジトリの中に保存
8. ServersパネルのTomcat11を右クリック
9. Add Deploymentを選択
10. Exploadedを選択 → multi-management-systemフォルダを選択
11. オプションパラメータを設定しますか？と聞かれるので現時点ではNoにする
12. デプロイ完了
